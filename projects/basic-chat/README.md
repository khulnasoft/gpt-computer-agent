# Basic Chat Agent

A simple conversational agent demonstrating the core GPT structure functionality.

## 🎯 **Features:**

- Basic conversation handling
- Memory management
- Tool integration
- Streaming responses
- Configuration management

## 📋 **Requirements:**

- Python 3.10+
- OpenAI API key
- Aideck GPT structure

## 🚀 **Setup:**

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set your OpenAI API key:
```bash
export OPENAI_API_KEY="your-api-key-here"
```

3. Run the chat agent:
```bash
python main.py
```

## 💬 **Usage:**

The chat agent will start an interactive session where you can:
- Send messages and receive responses
- Use built-in tools (calculator, weather, etc.)
- View conversation history
- Clear memory

## 🔧 **Configuration:**

Edit `config/config.yaml` to customize:
- Model selection
- Temperature settings
- Memory limits
- Tool configurations
