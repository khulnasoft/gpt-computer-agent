# Memory Management Example

Demonstration of the advanced memory management system in the GPT structure, including short-term, long-term, episodic, and semantic memory.

## 🎯 **Features:**

- Multi-tier memory system
- Semantic search capabilities
- Memory prioritization
- Automatic cleanup
- Memory analytics
- Context optimization
- Memory persistence

## 📋 **Requirements:**

- Python 3.10+
- OpenAI API key (for embeddings)

## 🚀 **Setup:**

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set environment variables:
```bash
export OPENAI_API_KEY="your-api-key-here"
```

3. Run the example:
```bash
python main.py
```

## 🧠 **Memory Types:**

### Short-term Memory
- Current conversation context
- Temporary working data
- Recent interactions

### Long-term Memory
- Persistent knowledge
- User preferences
- Learned information

### Episodic Memory
- Specific events
- Conversational episodes
- Contextual experiences

### Semantic Memory
- General knowledge
- Concepts and relationships
- Factual information

## 💡 **Examples:**

- Store user preferences in long-term memory
- Remember previous conversations
- Search for relevant memories
- Analyze memory usage patterns
- Optimize context for better responses
