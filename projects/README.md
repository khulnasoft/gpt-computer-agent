# Aideck GPT Agent Projects

This directory contains example projects and demonstrations of the GPT structure implementation.

## 📁 **Project Structure:**

```
projects/
├── README.md                    # This file
├── basic-chat/                  # Basic chat agent example
├── tool-integration/            # Advanced tool integration
├── memory-management/           # Memory system demonstration
├── multi-agent/                 # Multi-agent collaboration
├── streaming/                   # Streaming response examples
├── deployment/                  # Deployment configurations
└── templates/                   # Project templates
```

## 🚀 **Getting Started:**

Each project directory contains:
- `README.md` - Project description and setup
- `main.py` - Main application file
- `requirements.txt` - Project dependencies
- `config/` - Configuration files
- `tests/` - Test files

## 📚 **Examples:**

### Basic Chat Agent
A simple conversational agent using the GPT structure.

### Tool Integration
Advanced examples with custom tools and function calling.

### Memory Management
Demonstration of the memory system capabilities.

### Multi-Agent
Examples of multiple agents working together.

### Streaming
Real-time streaming response examples.

## 🛠️ **Running Examples:**

```bash
# Navigate to a project directory
cd projects/basic-chat

# Install dependencies
pip install -r requirements.txt

# Run the example
python main.py
```
